Installation instructions
Download the mod archive and extract it.
You will find a modified

Lucius.exe

Go to your game's installation folder, usually located at:

C:\Program Files (x86)\Steam\steamapps\common\Lucius
Replace the original (Lucius.exe)
Launch the game and enjoy!

Main features
Instant Boot: Skips all unskippable intro logos and videos.
Crystal Clear Camera: Completely disables all forms of camera motion blur, radial blur, and smearing.
Plug & Play: Simple .exe replacement with no complex mod managers or injectors required.
